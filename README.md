## Windows Log Analysis & Threat Detection

This project demonstrates how security analysts detect suspicious activity by analyzing Windows logs and identifying potential threats.

---

## Project Overview

The goal of this project is to simulate how a SOC analyst investigates logs to identify malicious or suspicious behavior.

The project includes:
- Log analysis  
- Detection logic  
- Example attack patterns  
- SIEM-style queries  

---

## Objectives

- Understand Windows logging  
- Identify suspicious patterns  
- Detect potential attacks  
- Build detection thinking  

---

## Key Focus Areas

- Failed login attempts  
- Privilege escalation  
- Suspicious processes  
- Unusual system behavior  

---

## SOC Relevance

SOC analysts rely heavily on log analysis to:
- Detect attacks  
- Investigate incidents  
- Correlate events  

This project simulates real-world SOC workflows.

---

## Project Structure

- logs → raw log data  
- analysis → investigation  
- detection → detection rules  
- queries → SIEM queries  

---

## 📌 Key Takeaway

Logs tell a story — detection is about connecting the dots.
